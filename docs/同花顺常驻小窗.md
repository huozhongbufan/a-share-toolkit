# 同花顺常驻小窗

> **一条命令：** `python run.py ths`
> 作用：把同花顺拉起来、摆到屏幕右下角一个小窗里，之后 `run.py look` 随时能读，
> **不弹窗、不抢焦点、不打断你正在做的事。**

---

## 为什么需要这个

`run.py look` 靠截屏 + 本地视觉模型读同花顺界面。所以同花顺必须一直开着。

但有两个实际问题：

1. **全屏开着占地方**，而且 `look` 每次调用都会把它弹到最前面、抢走焦点
2. **最小化又读不到** —— 最小化的窗口截出来是空白

所以要的是第三种状态：**挂在角落的小窗，不激活、不遮挡主要内容。**

---

## 用法

```bash
python run.py ths                    # 启动并摆到右下角（默认 1350x620）
python run.py ths --status           # 只看状态，不动窗口
python run.py ths --corner topleft   # 换个角
python run.py ths --width 1350       # 调宽度
python run.py ths --capture          # 摆好后试抓一张，确认能读
```

输出：

```
同花顺在跑：
  PID 18212  「同花顺(9.60.20) - 自选股」

摆成小窗中（不会抢焦点）…
  同花顺已摆到 bottomright：1350x620 @ (1198,808)
```

然后：

```bash
python run.py look
```

---

## 尺寸为什么是 1350×620

实测的：

| 宽度 | 能看到的列 | 能不能用 |
|---|---|---|
| 953（THS 最小宽度） | 只有代码、名称 | ❌ 没价格，读了没用 |
| 1150 | 代码、名称、涨幅 | 🟡 够但挤 |
| **1350** | 代码、名称、**涨幅、现价、涨跌** | ✅ **用这个** |

宽度再大就接近全屏，失去「小窗」的意义。

---

## 关键技术：PrintWindow，不是 CopyFromScreen

旧版截图是三步：

```powershell
ShowWindow($h, 9)          # SW_RESTORE —— 把最小化的窗口弹回来
SetForegroundWindow($h)    # 抢焦点
CopyFromScreen(...)        # 只能拍可见区域
```

**每次 `look` 都会把同花顺弹出来并抢走焦点。** 与「挂个小窗」的用法直接冲突。

现在改成 `PrintWindow(hwnd, hdc, 2)`：

| | CopyFromScreen | **PrintWindow** |
|---|---|---|
| 需要窗口在最前 | ✅ 必须 | ❌ 不需要 |
| 会移动窗口 | ✅ 会（还原） | ❌ 不会 |
| 会抢焦点 | ✅ 会 | ❌ 不会 |
| 最小化窗口 | 拍不到 | **也可能是空白** |

`flags=2` 是 `PW_RENDERFULLCONTENT`。同花顺是 Chromium 类窗口，
不带这个标志会截出空白。老程序不支持时报错并退回 `flags=0` 再试一次。

**最小化的窗口 PrintWindow 通常返回空白** —— 这种情况明确报
`window_minimized` 错误，不会保存一张黑图冒充成功。

## 踩过的四个坑

### 坑 1：`.ps1` 没有 BOM，中文注释把语法打乱

Windows PowerShell 5.1 读 `.ps1` 时**没有 BOM 会按 GBK 解码**。
文件里的中文注释会被解成乱码，把注释行和下一行代码粘在一起，报
「字符串缺少终止符」「表达式或语句中包含意外的标记」。

**修法**：给 `.ps1` 加 UTF-8 BOM。
`ec/screen.py` 写临时脚本时也会补一个。

### 坑 2：双重 BOM 让 `param()` 失效

加了 BOM 之后又踩了一次：文件本身有 BOM，`screen.py` 又加了一个，
变成 `EF BB BF EF BB BF`。第二个 BOM 让 `param()` 块不被识别，
**所有参数变成 null**，最后在 `$bmp.Save()` 处报 `ArgumentNullException`。

**修法**：`return "\ufeff" + src.lstrip("\ufeff")` —— 先去掉再加。
并且把 `param()` 放在文件第一行（注释之前）。

### 坑 3：调了 SetProcessDPIAware 会截出大片白边

调了之后 `GetWindowRect` 返回物理像素（2582×1449），
但 `PrintWindow` 只把内容画在左上角一块，右边和下面全是白的。

**修法**：**不调** `SetProcessDPIAware`。用逻辑像素（1721×966），
和 PrintWindow 输出尺寸一致，正好贴合。

### 坑 4：摆一次尺寸会被同花顺改回去

刚启动时主窗口是「登录到全部行情主站」，那时候摆尺寸没用——
登录完成后窗口会自己变回全屏。

**修法**：等窗口标题不再是「登录/连接/正在/加载/启动」，再连摆三次（间隔 1 秒）。

## 排查表

| 现象 | 原因 | 处理 |
|---|---|---|
| `process_not_running` | 同花顺没开 | `python run.py ths` |
| `window_minimized` | 被最小化了 | `python run.py ths` 重新摆成小窗 |
| `blank_capture` | 窗口内容全黑 | 换 `python run.py ths --width 1350` 重摆；或该界面是硬件加速渲染 |
| `printwindow_failed` | 窗口不支持 PrintWindow | 少见。退回整屏模式：`run.py look --screen` |
| 截图有白边 | 调了 DPI aware | 已修，若复发检查 `_capture.ps1` 里有没有 `SetProcessDPIAware` |
| 读到的行比别人少 | 窗口太窄，列被挤掉 | `--width 1350` |
| 多出一行「代码 名称」 | 表头被当成数据 | 已修（`_is_header_row`） |

## 一句话

**同花顺不是「要打开才能用」的软件，是「一直挂着、随时能读」的窗口。**

`python run.py ths` 一次，之后 `look` 随便调，它不会跳出来烦你。
