# 工作台面板（贴着同花顺）

> **一条命令：** `python run.py dock`
> 在屏风旁边挂一块无边框置顶面板，一眼看到账户、待办、行情时间、花费。

---

## 先回答「能不能把工作台塞进同花顺」

**不能。** 同花顺没有公开的插件接口，也不给源码，注入或内嵌都不可行。

**但可以做等效的事**：一个**独立的无边框置顶窗口**，贴在同花顺旁边，
视觉上拼成一块。不动同花顺内部，也不需要它的配合。

这个方案的边界要说清楚：

| 能 | 不能 |
|---|---|
| 贴在窗口旁边，跟着移动 | 真的「长在」同花顺界面里 |
| 置顶显示，不切换终端就能看 | 改同花顺的任何界面 |
| 拖动、调宽度、关掉 | 面板里下单 |

---

## 可行性验证（先验，再造）

三项都实测过，**零第三方依赖**：

| 项 | 结果 |
|---|---|
| `tkinter` 可用 | ✓ Tk 8.6（标准库） |
| 读同花顺窗口位置 | ✓ `ctypes` + `user32`：hwnd=67840 (799,539) 900x413 |
| 无边框置顶窗口 | ✓ 可创建、可关闭 |
| **跟随移动** | ✓ 同花顺 799→787，面板 411→399，间隙恒为 8px |

## 贴哪边是算出来的

实测屏幕 1707x960（逻辑像素），同花顺 (799,539) 900x413：

```
右边缘 1699 → 右边只剩 22px   ← 贴不了
下边   952  → 只剩 8px        ← 贴不了
左边   799  → 空出 799px      ← 只能贴左边
```

所以默认 `贴左边：(411,539) 380x470`。

同花顺最大化时四面都没空间，退化成「浮在右上角的置顶小窗」，标题栏会写
`浮动（同花顺占满屏）`。

**用户手动拖过之后就不再自动摆位置** —— 尊重他的选择。

## 一个必须记住的设计决定

**面板里唯一发网络请求的地方，是查一只标的的实时快照。**

第一版为了「快」，用的是上次 `train` 记录里的时间戳，标签写着**「行情时间」**。
面板上显示 `10:16:50 · 51 分钟前` —— 看的人会以为那是实时价格。

**那是最危险的一种误导**：数字是真的，标签是假的。

所以宁可每次刷新多一个请求（约 0.3 秒），也要让时间戳说的是它自己。

## 排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板不出现 | 同花顺没跑 → 应该浮在右上角 | 看右上角；`--check` 看算出来的位置 |
| 面板位置怪 | 手动拖过，不再自动摆 | 关掉重开 |
| 内容全 `—` | `collect()` 抛异常 | 底部红字会写原因 |
| 行情显示「拿不到」 | 腾讯接口失败或断网 | 面板其它部分仍可用 |
| 面板挡住同花顺 | 同花顺占满屏，只能浮动 | 把同花顺调小（`run.py ths --width 1350`） |
| 整屏截图全黑但窗口能截 | 屏幕锁定/显示器关闭 | `CopyFromScreen` 的限制，`PrintWindow` 不受影响 |

## 技术要点

| 需求 | 怎么做 |
|---|---|
| 无边框 | `root.overrideredirect(True)` |
| 置顶 | `root.attributes("-topmost", True)` |
| 找同花顺 | `ctypes` EnumWindows + 标题含「同花顺」 |
| 读位置 | `GetWindowRect` |
| 跟随 | `root.after(1200, self._follow)` 轮询 |
| 不卡 UI | 数据刷新走 `threading` + `queue`，用 `after` 回主线程 |
| 不抢焦点 | 摆自己位置用 `geometry()`，不动别人 |

**不调 `SetProcessDPIAware`。** 调了之后坐标是物理像素、Tk 是逻辑像素，
两边对不上。不调的话两边都是逻辑像素，一致。

## 和同花顺小窗的关系

| 命令 | 干什么 |
|---|---|
| `python run.py ths` | 把**同花顺**摆成小窗（1350x620），好让 `look` 能读全字段 |
| `python run.py dock` | 在**同花顺旁边**挂一块状态面板 |

两个可以同时用：

```bash
python run.py ths --capture    # 同花顺摆好 + 试抓一张
python run.py dock             # 旁边挂面板
```

---

## 一句话

**它不是把工作台塞进同花顺，是让两块窗口在视觉上拼成一块。**

改不了别人的软件，就改变自己窗口的位置。
